## Quick start

```typescript title="lib/bot.ts" lineNumbers
import { Chat } from "chat";
import { createMemoryState } from "@chat-adapter/state-memory";
import { createFooAdapter } from "YOUR_PUBLISHED_ADAPTER_PACKAGE";

export const bot = new Chat({
  userName: "mybot",
  adapters: {
    foo: createFooAdapter({
      apiKey: process.env.FOO_API_KEY,
      webhookSecret: process.env.FOO_WEBHOOK_SECRET,
    }),
  },
  state: createMemoryState(),
});

bot.onDirectMessage(async (thread, message) => {
  await thread.post(`You said: ${message.text}`);
});
```

The memory state adapter keeps subscriptions and locks in process memory, which suits local development. Use [Redis](/adapters/official/redis) or [PostgreSQL](/adapters/official/postgres) in production.

Then create the webhook route:

```typescript title="app/api/webhooks/foo/route.ts" lineNumbers
import { bot } from "@/lib/bot";

export async function POST(request: Request): Promise<Response> {
  return bot.webhooks.foo(request);
}
```

## Platform setup

{/* Optional. Numbered steps in the vendor's dashboard. Match UI labels

1. In the Foo dashboard, create an app and copy its **API key** into `FOO_API_KEY`.
2. Under **Webhooks**, set the URL to your deployed `/api/webhooks/foo` route and subscribe to message events.
3. Copy the **Signing secret** into `FOO_WEBHOOK_SECRET`.

## Webhooks

{/* Optional. Which events the adapter handles and how it verifies them. */}

The adapter handles Foo `message.created` events and ignores other event types. It verifies each request's signature with `webhookSecret` and returns `401` when verification fails.
